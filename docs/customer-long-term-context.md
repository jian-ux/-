# 客户长期上下文

## 客户身份

当前客户唯一键为 `channel_type + channel_user_id`。不同渠道的同一自然人暂不自动合并；跨渠道统一客户 ID、登录账号或手机号绑定属于后续能力。

## 会话与历史

会话关闭后不会重新打开。客户发送新消息时仍创建新会话；管理端客户详情页通过 `/api/admin/customer/{id}/timeline` 按创建时间升序展示该客户在所有未删除会话中的完整消息时间线。

## 长期记忆准入

仅从客户明确、稳定的表达中提取企业名称、客户身份、产品、套餐/版本和使用渠道。手机号、邮箱、身份证、地址等敏感信息先脱敏；否定表达和不明确推断不写入长期记忆。显式修正才会替换已有事实。`playground` 渠道不写入客户级长期数据。

长期摘要和结构化记忆会在上下文中以独立的“客户长期摘要/客户长期记忆”区块注入，并明确标注为客户资料而非知识库事实。知识库检索只使用知识库数据，不读取客户记忆。

## 图片记忆

客户图片及 OCR 元数据写入 `bot_customer_media`，信任级别固定为 `UNTRUSTED`，仅用于客户资料留存，不建立知识库关联、不参与知识库检索。`playground` 图片仍只属于临时会话范围。

## 数据库迁移

执行 `feisheng-bot-parent/sql/43_add_customer_long_term_context.sql`，新增客户长期摘要、结构化记忆和图片记忆表。
