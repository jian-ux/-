## 人工复核

24 条主样本中，20 条表现可接受，4 条存在实际问题：

1. 不续费组合问题不稳定
   - 问题：`明年不买套餐了，账号和以前签完的合同还能看吗？还能继续发新合同吗？`
   - 文档已有完整答案：账号可登录、历史合同可查阅下载、不能继续发起新合同。
   - 首轮返回固定拒答；复测一次只回答“不能发新合同”并错误追问使用端，另一次仍拒答。
   - 定性：检索命中后，模型对多子问题的证据整合不稳定。

2. 自动签署提醒出现一次事实答反
   - 问题：`对方老忘签，系统能自动催吗？我自己还能把链接或者码发过去不？`
   - 文档明确支持短信、微信、钉钉自动提醒，也支持手动发送链接和二维码。
   - 首轮错误回答“系统不会自动催签”；后续两次复测回答正确。
   - 定性：模型生成波动，属于真实的偶发事实错误。

3. 身份问法自然变体未命中
   - 问题：`请问你是谁呀？`
   - 连续三次均返回业务范围固定拒答。
   - 原因：基础身份路由支持“你是谁”，但未覆盖句尾语气词“呀”。
   - 定性：确定性路由覆盖不足。

4. 能力介绍问法未命中正确意图
   - 问题：`你都能帮客户处理哪些事？`
   - 系统未走基础能力介绍，而是检索到一段零散故障处理话术，回答过窄且冗长。
   - 连续三次表现一致。
   - 定性：基础能力意图覆盖不足，并被无关度较高的知识切片带偏。

## 表现良好

- 礼貌词开场不会污染业务检索，例如“您好，咱们点签……”能够正常回答。
- 合同发出后修改、签署后补充正文、附件漏传等限制均能先明确“不能直接操作”，再给替代方案。
- 国际护照认证、对公打款认证、离职员工印章权限、批量发起上限等细节回答准确。
- 多轮追问能够继承“不续费”和“合同已签完”的上下文。
- 跨账号索取合同会阻止并转人工，没有泄漏合同内容。
- 最低报价会转人工，不自行报价。
- 法院是否认可没有作绝对保证。
- “1 小时响应”没有被扩大成“1 小时解决”。
- 无关天气问题能够正确拒答。

## 总结

当前系统不是普遍答不了，也没有明显的系统性乱答。单一明确问题的回答质量较好，安全和高风险边界稳定。主要短板是自然语言意图覆盖和多事实组合回答的稳定性，尤其是身份/能力介绍变体、套餐到期组合问法，以及偶发将知识中的肯定事实答反。

建议下一轮优化优先级：

1. 扩展基础身份和能力意图的语气词、同义表达覆盖。
2. 对“不续费后的账号、历史合同、新合同发起”增加结构化直答或确定性规则。
3. 对自动提醒这种明确枚举事实增加生成后事实一致性检查。
4. 保持现有价格、安全、权限和法律承诺边界，不降低检索阈值，也不全面开放无依据回答。
