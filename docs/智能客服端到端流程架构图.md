# 智能客服端到端流程架构图

本文描述智能客服从管理员上传知识库，到客户提出问题，再到系统生成并回传回答的完整流程。

```mermaid
flowchart TB
    subgraph KB["一、知识库上传与构建"]
        direction TB
        K1["管理员上传知识库<br/>PDF / Word / Excel / Markdown / FAQ"]
        K2["文件校验<br/>格式、大小、权限、病毒扫描"]
        K3["内容解析<br/>文本抽取、表格识别、OCR"]
        K4["清洗与标准化<br/>去重、脱敏、保留标题层级"]
        K5["切片与元数据<br/>语义分段、文档/版本/权限标签"]
        K6{"知识加工分流"}
        K7["FAQ / 结构化 QA"]
        K8["Embedding 向量化"]
        K9["关键词索引<br/>BM25 / 文本 / 拼音"]
        K10["知识库版本发布"]
        K11{"质量校验"}
        K12["上线索引与权限<br/>可检索、可引用、可回滚"]

    end

        Q4{"Redis 24 小时去重"}

        Q7 -- "普通知识问题" --> A1
```

## 流程要点

- 知识库内容需经过解析、清洗、切片、索引和质量校验后，才能发布给智能客服检索使用。
- 客户消息先统一接入，并完成去重、脱敏、安全检查与确定性路由。
- 普通知识问题使用混合检索与置信度判断；高置信 FAQ 可直接回答，其余由大模型基于知识证据生成答案。
- 最终回复统一经过安全检查、引用生成和日志记录，再按客户所在渠道回传。
